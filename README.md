# ВинилБро70

Сайт детейлинг-студии «ВинилБро70» в Томске. [Открыть сайт](https://ia7052476-dotcom.github.io/vinylbro70/) · [Посмотреть работы](https://ia7052476-dotcom.github.io/vinylbro70/works.html).

## Локальная сборка

Для сборки понадобится Node.js. Выполните команду в корне репозитория.

```sh
node build.mjs
```

Откройте `docs/index.html` в браузере. Фотографии и шрифты входят в проект. Для загрузки карты и перехода в мессенджеры нужен интернет.

## Обновление сайта

- `catalog.mjs` содержит проекты, группы фотографий, услуги и отзывы.
- `components.mjs` отвечает за разметку страниц и разделов.
- `docs/styles.css` и `docs/app.js` содержат оформление и логику интерактивных элементов.
- `docs/assets/` содержит фотографии WebP, их уменьшенные версии, шрифты и библиотеку карты.
- `sources.json` хранит ссылки на исходные фотографии и тип авторства.

После правок в каталоге или компонентах снова запустите `node build.mjs`. Сохраните исходники и обновлённую папку `docs` в одном коммите и отправьте его в ветку `main`. GitHub Pages публикует сайт из папки `/docs` этой ветки. При переносе на другой адрес замените значение `url` в `build.mjs` перед сборкой.
