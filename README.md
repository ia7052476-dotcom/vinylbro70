# ВинилБро70

Готовый сайт находится в папке `dist`. Для просмотра откройте `dist/index.html` в браузере. Фотографии и шрифты уже включены в проект. Для загрузки карты и перехода в мессенджеры нужен интернет.

## Обновление сайта

- `catalog.mjs` содержит проекты, группы фотографий, услуги и отзывы.
- `components.mjs` отвечает за разметку страниц и разделов.
- `dist/styles.css` и `dist/app.js` содержат оформление и логику интерактивных элементов.
- `dist/assets/` содержит фотографии WebP, их уменьшенные версии, шрифты и библиотеку карты.
- `sources.json` хранит ссылки на исходные фотографии и тип авторства.

После изменения каталога или компонентов запустите `node build.mjs` из корня проекта. Дополнительные пакеты для сборки не нужны. На статический хостинг загружается содержимое `dist`. При переносе на собственный домен замените значение `url` в `build.mjs` перед сборкой.
